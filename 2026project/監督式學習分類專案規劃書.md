## 1. 專案概述（Project Overview）

### 1.1 專案背景與動機
在網路媒體與社群平台中，標題黨（Clickbait）常以誇大、懸疑或情緒化的標題吸引點擊，影響閱讀體驗與資訊可信度。本專案旨在透過自然語言處理（NLP）與監督式機器學習技術，自動辨識英文新聞／文章標題是否屬於標題黨。

### 1.2 專案目標
- **主要目標**：針對輸入的英文標題文字（`headline`），建立一套可重現、高準確率且低延遲的二元分類模型，預測其是否為標題黨（`clickbait`）。
- **分類類型**：**二元文本分類（Binary Text Classification）**
- **預期產出**：
  1. 標題文字探索性資料分析（EDA）報告（字詞分布、句長與 N-gram 觀察）
  2. 可重現的文本前處理與向量化管線（TF-IDF / Embedding Pipeline）
  3. 多模型實驗比較表與最佳模型權重檔
  4. 模型評估報告與誤判案例分析（Error Analysis）

## 2. 問題定義與成功標準（Problem Definition & Success Criteria）

### 2.1 輸入與輸出定義
| 項目 | 說明 |
| :--- | :--- |
| **預測目標（Label / `clickbait`）** | `1` = 標題黨（Clickbait），`0` = 正常新聞標題（Non-Clickbait） |
| **輸入特徵（Feature / `headline`）** | 英文標題純文字（例如：`"Which TV Female Friend Group Do You Belong In"`） |
| **推論方式** | 支援單筆／批次標題推論，輸出類別標籤與預測機率（`predict_proba`） |

### 2.2 業務與技術成功指標
- **基準線（Baseline）**：以 TF-IDF + Logistic Regression 建立基準效能（預期 F1-Score $\ge$ 0.90）。
- **目標效能**：測試集 **Accuracy $\ge$ 0.95**、**F1-Score $\ge$ 0.95**、**ROC-AUC $\ge$ 0.98**。
- **效能約束**：單筆標題推論延遲 < 20ms（適合即時內容過濾或 API 部署）。

## 3. 資料規劃（Data Strategy）

### 3.1 資料集現況盤點（`clickbait_data.csv`）
經初步檢視，資料集具備以下特性（資料品質極佳）：

| 檢核項目 | 實際結果 |
| :--- | :--- |
| **總樣本數** | 32,000 筆 |
| **欄位結構** | `headline`（文字）、`clickbait`（標籤：`0` / `1`） |
| **類別分布** | `1`（標題黨）：15,999 筆（49.997%）<br>`0`（正常標題）：16,001 筆（50.003%）—— **類別高度平衡** |
| **缺失與格式異常** | 0 筆（無缺失值或格式錯誤列） |
| **重複標題** | 0 筆（32,000 筆皆為唯一標題） |
| **單篇字數統計** | 最短 1 字、平均 9.07 字、最長 26 字（屬於短文本分類任務） |

### 3.2 資料切分策略（Data Splitting）
由於類別幾乎完全平衡且無重複資料，採用分層抽樣（`StratifiedShuffleSplit` / `train_test_split(..., stratify=y)`）確保各集合維持 50:50 比例：
- **訓練集（Train Set）**：70%（22,400 筆，搭配 5-Fold Stratified Cross-Validation 進行調參）
- **驗證集（Validation Set）**：15%（4,800 筆，用於模型選擇與閾值確認）
- **測試集（Test Set）**：15%（4,800 筆，完全隔離，僅於最終階段進行一次效能評估）

## 4. 探索性資料分析與文本前處理（EDA & Text Preprocessing）

### 4.1 探索性資料分析（EDA）重點
- 比較兩類別的標題長度（字元數、單字數）分布差異。
- 分析標點符號與句型特徵（如問號 `?`、驚嘆號 `!`、數字開頭如 `"17 Things..."`、人稱代詞 `"You"` / `"Your"` 出現頻率）。
- 繪製兩類別高頻 Uni-gram / Bi-gram 關鍵字排行，觀察詞彙差異。

### 4.2 文本前處理與特徵工程管線（Pipeline）
所有向量化轉換器僅能使用 **訓練集** `fit()`，再對驗證集與測試集進行 `transform()`，嚴防資料洩漏：

1. **文字清理（Text Cleaning）**：
   - 統一轉小寫（Lowercasing，視實驗決定是否保留大小寫特徵，因首字母大寫格式在英文標題中可能具有區分力）
   - 空白字元正規化（去除多餘空格與換行符號）
   - 保留數字與關鍵標點符號（或額外抽取成數值特徵，避免過度清理導致標題黨語氣特徵流失）
2. **特徵表示法（Text Vectorization）**：
   - **詞袋／TF-IDF 特徵**：`TfidfVectorizer(ngram_range=(1, 2), max_features=20000, sublinear_tf=True)`
   - **人工統計特徵（可選強化）**：字數、字元數、是否含問號/驚嘆號、是否以數字開頭（如 Listicle 常見格式）
   - **進階語意特徵（可選比較）**：預訓練詞向量或輕量 Transformer Embedding（如 `DistilBERT` / `MiniLM`）

## 5. 模型選擇與訓練策略（Modeling & Training）

### 5.1 候選模型清單
本任務為中小型短文本分類（32,000 筆），先以高效能傳統機器學習模型為主，必要時再導入深度學習微調：

| 階段 | 模型名稱 | 選用理由 |
| :--- | :--- | :--- |
| **Baseline** | TF-IDF + Multinomial Naive Bayes / Logistic Regression | 文本分類經典基準，訓練極快、具高維稀疏特徵處理能力且可直接檢視正負權重詞彙 |
| **線性邊界強化** | TF-IDF + LinearSVC（或 SGDClassifier） | 在高維 TF-IDF 空間中通常表現優異，邊界泛化能力佳 |
| **整合樹模型** | LightGBM / Random Forest（搭配 SVD 降維或統計特徵） | 用於驗證非線性特徵組合（如統計特徵＋文字向量）是否能再提升表現 |
| **進階深度學習（選用）** | Fine-tuned DistilBERT / RoBERTa | 若線性模型已達 96%+，可作為上限對照組比較語意理解增益與推論成本 |

### 5.2 超參數調校（Hyperparameter Tuning）
- 使用 `Pipeline` 串接 `TfidfVectorizer` 與分類器，透過 `GridSearchCV` 或 `RandomizedSearchCV` 同時調整 `ngram_range`、`min_df`、`max_features` 與正則化參數 `C`（或 `alpha`）。
- 固定 `random_state=42` 確保實驗完全可重現。

## 6. 模型評估指標（Evaluation Metrics）

因類別比例為 50:50，各項分類指標皆具高度參考價值：

- **混淆矩陣（Confusion Matrix）**：檢視正常標題被誤判為標題黨（FP）與標題黨漏抓（FN）的比例。
- **Accuracy（準確率）**：整體分類正確率。
- **Precision、Recall 與 F1-Score**：確認兩類別表現是否均衡，避免單邊偏誤。
- **ROC-AUC 與 Log Loss**：評估模型輸出機率的校準度與排序能力。
- **模型可解釋性（Explainability）**：輸出 Logistic Regression / LinearSVC 權重最高的前 20 個「標題黨特徵詞」與「正常新聞特徵詞」，並檢視誤判樣本找出改進方向。

## 9. 風險評估與應對策略（Risks & Mitigation）

| 潛在風險 | 影響程度 | 應對策略 |
| :--- | :---: | :--- |
| **資料洩漏（Data Leakage）** | 高 | 嚴格將 `TfidfVectorizer` 放入 `sklearn.pipeline.Pipeline`，確保詞彙表與 IDF 權重僅由訓練集學習。 |
| **領域偏移（Domain Shift）** | 中 | 資料集多為特定時期英文媒體標題（如 2015–2016 流行文化與新聞），上線前需留意對現代新詞或不同領域標題的泛化能力。 |
| **過度依賴特定關鍵字** | 中 | 透過錯誤分析檢查模型是否過度記住特定專有名詞（如明星、電影名稱），必要時調整 `min_df` 或加入正則化。 |
